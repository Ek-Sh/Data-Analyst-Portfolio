# Автоматизация обработки данных сервиса «Яндекс Книги» в Airflow

***СТАТУС:***  **Завершён**

## Цель проекта:

Настроить автоматизированный пайплайн обработки пользовательской активности сервиса Яндекс Книги.

В рамках проекта необходимо:
1. Создать DAG в Apache Airflow.
2. Настроить проверку появления входного файла в S3.
3. Запускать PySpark-задачу на Yandex DataProc.
4. Рассчитывать пользовательские агрегаты.
5. Загружать результат в ClickHouse.

##Описание проекта:
В проекте настроен ежедневный пайплайн обработки данных сервиса Яндекс Книги.
Airflow проверяет появление файла с пользовательской активностью в S3 и после его появления запускает PySpark-приложение. Spark-скрипт обрабатывает данные, рассчитывает агрегаты по пользователям и сохраняет результат в ClickHouse.

Схема пайплайна:
S3 → Airflow → PySpark → ClickHouse

## Результат проекта:

Настроен ежедневный DAG с отключённым запуском за пропущенные даты.
S3KeySensor проверяет появление входного файла каждые 5 минут с максимальным временем ожидания 1 час.
После появления данных запускается PySpark-задача на Yandex DataProc.
Для каждого пользователя рассчитываются количество уникальных сессий audition_count и средняя продолжительность сессии avg_hours.
Итоговые данные загружаются в ClickHouse.
В результате выполнения пайплайна сформирована таблица из 2 163 строк.

## Технические особенности проекта:
В Airflow настроены две основные задачи:
S3KeySensor — ожидание входного файла;
DataprocCreatePysparkJobOperator — запуск PySpark-приложения.

Зависимость настроена так, чтобы обработка запускалась только после появления данных:
wait_for_input >> run_pyspark
